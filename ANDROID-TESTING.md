# Test Cue on Android

Use the preview APK generated by the `preview` EAS build profile. It installs independently and does not require Expo Go or the development server.

1. Install and open Cue. Confirm the three sample scripts appear.
2. Create a script with several paragraphs, save it, then open it again.
3. Close Cue fully and reopen it. Confirm the script and favourites remain.
4. Read the script. Start, pause, resume, restart, and swipe to a different position.
5. Change the speed and text size. Check that mirror mode reverses only the script.
6. Rotate the phone between portrait and landscape. Check the reading controls remain usable.
7. Start the countdown, pause before it finishes, and confirm scrolling does not begin.
8. Switch to another app during playback and return. Confirm Cue is paused.
9. Turn on airplane mode and repeat the reading flow. It should work offline.
10. Leave an unsaved edit and press Android Back. Confirm that you can keep editing.
11. Read for longer than the phone's normal screen timeout. Confirm the screen stays awake while the reader is open.

Do not uninstall or clear app data to test persistence: both intentionally remove the local library. This version has no library backup/export. Use sample text for testing.

Record the phone model, Android version, and steps for any issue. A successful cloud build establishes that the APK compiled; it does not establish all of these device behaviors.
